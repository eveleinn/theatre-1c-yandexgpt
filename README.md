# 🎭 Автоматизированная информационная система по бронированию и продажи театральных билетов (1С:Предприятие 8.3)

Внедрена интеграция YandexGPT для генерации описаний и аналитики, отправкой QR‑билетов по email и рекомендациями по выбору спектаклей.

## ✨ Функциональность

- **Репертуар и сеансы** – справочники спектаклей, актёров, жанров, мест, посетителей.
- **Бронирование и продажа** – контроль занятости мест, автоматическая проверка остатков.
- **Печать билетов** – печатная форма с QR‑кодом (генерация через внешний API).
- **Email‑уведомления** – отправка подтверждений брони и билетов с QR‑кодом при покупке через SMTP (Yandex).
- **Рекомендации** – подбор спектакля по жанру, бюджету и истории покупок при бронировании или продаже билета.
- **Искусственный интеллект**:
  - генерация описаний спектаклей;
  - финансовая аналитика с комментариями нейросети;
  - управленческая сводка с точками роста.
- **Отчёты** – расписание спектаклей
- **Резервное копирование** – автоматическая выгрузка .dt файла.
- **Ролевой доступ** – роли: администратор, кассир, бухгалтер, директор.
- **Проверка билетов** – сканирование QR‑кода при входе, защита от повторного использования.
